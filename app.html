Planning Guides (from the Training Script)

SMART Objectives Framework (Table 4)

LetterMeaningExample
S – SpecificClear what learners achieve“Convert decimal 0–15 to binary”
M – MeasurableObservable outcomes“Explain two traditional counting methods”
A – AchievableRealistic for time/resources“Represent numbers 0–15 in binary using beads”
R – RelevantAligned with syllabus; meaningful“Apply binary to computer data storage AND traditional pattern encoding”
T – Time-boundAchievable within timeframe“By end of 80-minute lesson”

Four Objective Dimensions (Table 5)

DimensionDescriptionExample
KnowledgeWhat learners should KNOW“Know binary number system and traditional counting”
SkillsWhat learners can DO“Convert numbers; create patterns”
ValuesDispositions to develop“Appreciate mathematical thinking across cultures”
IndicatorsObservable evidence“8/10 correct conversions; explains cultural significance”

Weak: “Learners will learn about algorithms.” Strong: “By end of lesson, learners will define algorithms (knowledge); create a 5-step algorithm and compare with traditional organisational methods, dare/nhimbe (skills); appreciate systematic problem-solving in both contexts (values); write a 5-step algorithm and identify 2 similarities (indicators).”

Recommended Methodologies (Table 6)

MethodWhen to UseIndigenous Knowledge Application
Project-Based LearningSynthesis and applicationProjects connect to heritage/traditional knowledge
Inquiry-BasedAnalysis, comparisonStart with observation; research includes traditional knowledge
Collaborative LearningTeamwork skillsGroups structured like dare/nhimbe; Ubuntu/Unhu/Vumunhu
Experiential / Hands-onSkill developmentLearn traditional practices by doing; experts demonstrate
StorytellingCultural significanceElders share stories; learners analyse embedded knowledge
Community-BasedLocal resources essentialVisit heritage sites; observe practices; interview knowledge holders

Key point: methodology must match the objective. Indigenous knowledge and school-based projects should be woven throughout — in objectives, activities and resources — not added as afterthoughts.

Assessment Principles (Table 7) & Reflection Questions (Table 8)

PrincipleDescription
AuthenticAssess in real-world contexts
ContinuousFormative (ongoing) and summative (periodic)
Multiple methodsObservation, product, performance, tests, self/peer assessment
HolisticKnowledge, skills and values; process matters
Transparent criteriaShare rubrics in advance; clear success criteria

Reflect after each lesson: Did learners achieve objectives (evidence)? Did methods enable learning? Did assessment measure objectives? Were objectives, methods and assessment aligned — and was indigenous knowledge authentic?

Competence Framework (Table 1)

BeginningDevelopingEmbeddingProficient
Understand the need for planning but struggle to connect yearly objectives to daily lessons; plans lack alignment. Create basic scheme-cum-plans with some alignment; sometimes identify appropriate methods and assessment. Regularly create well-aligned plans with clear vertical coherence; select appropriate methodologies and aligned assessments. Confidently create comprehensive plans with seamless alignment; strategically select diverse methodologies and sophisticated assessments.
